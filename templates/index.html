Introduction

What Is This
System?

This platform leverages three powerful machine learning classifiers to detect spam messages in real time. Each model independently analyses the input and provides a probability score, accuracy metric, and full confusion matrix — giving you deep, explainable AI-driven insights.

Built with Python Flask on the backend and a futuristic glassmorphism UI on the frontend, this tool is ideal for cybersecurity research, academic projects, and enterprise-level email/SMS threat detection.

Services

What We Offer

Three specialised ML services working together to give you the most reliable spam verdict.

Naive Bayes Classifier
A probabilistic model based on Bayes' theorem. Fast, lightweight, and highly effective for text classification. Serves as the primary decision model for the final verdict.
Logistic Regression
A linear model that predicts spam probability using learned word-feature weights. Provides well-calibrated confidence scores for each message analysed.
Random Forest
An ensemble of decision trees that votes on the final outcome. Robust against noisy or adversarial inputs, making it ideal as a cross-validation layer.
NLP Text Preprocessing
Automated stopword removal, lowercasing, special character stripping, and TF-IDF vectorisation transform raw text into clean machine-readable feature vectors.
Confusion Matrix Report
Each model returns a full confusion matrix — True Positives, True Negatives, False Positives, and False Negatives — for complete performance transparency.
Accuracy & Probability Scoring
Every prediction comes with a model accuracy percentage and individual spam/not-spam probability scores displayed as animated progress bars.
